# Cyprus Schengen Monitor

A static, source-linked monitor of Cyprus's accession to the Schengen area.

Production URL: https://chistopat.github.io/cyprus-schengen-monitor/

The Russian edition is at the project root. English is under `en/`; Greek for Cyprus (`el-CY`) is under `el/`. Every edition includes the overview, timeline, forecast, participants, sources and privacy pages. The information snapshot is dated 27 November 2026. Political targets and analytical scenarios are distinguished from adopted legal decisions.

## Build and check

Python 3.12 and Node.js are sufficient for the website build and checks. No package installation is needed.

```sh
python build.py
python scripts/audit_site.py
node --check dist/assets/site.js
node --check dist/assets/analytics.js
python -m http.server 8765 --directory dist
```

`build.py` generates the Russian pages, then `scripts/localize.py` builds all language versions, metadata and the multilingual sitemap. `content/monitor.json` holds events and source URLs, including the chronology from 1999 onward. Events with approximate or multiple dates use `date_label` and `date_precision`; their ISO `date` is a sorting anchor, not a more precise historical claim. `provenance` separates source dates and document status from the event itself. `translations/{ru,en,el}.json` contains aligned interface text; `translations/chronology-{en,el}.json` holds complete event translations keyed by `chronology_number` and source labels. The build stops if a translation is missing. `content/seo.json` holds unique page titles and descriptions. `site.json` contains the production URL, public GA4 Measurement ID and optional search-engine verification tokens. Never put credentials or Analytics API secrets there.

The map variants are committed assets. To regenerate them, install Pillow, NumPy and SciPy locally, then run `python content/illustrate.py --language en` (or `ru`/`el`). Font lookup supports the original Linux fonts and macOS system fonts.

## Publication

The GitHub Actions Pages workflow builds the website, audits its metadata and links, checks JavaScript syntax and deploys `dist/` on pushes to `main`. GitHub Pages must use GitHub Actions as its publishing source. No advertising campaign or Google Ads billing is required to host the website or collect GA4 statistics.

## Analytics and search

GA4 uses Measurement ID `G-TPP3V2T4J9`. Analytics loads only after consent; preview hosts do not send events. Tracked interactions include page views, source-link clicks, timeline filters and opening timeline entries. On-site search text is not sent. Visitors can change consent on the privacy page. Advertising personalisation and Google Signals are disabled in the tag configuration.

The official Google Analytics MCP is configured separately in the user's Codex settings. Its OAuth credentials must remain outside this repository. Authenticated account discovery and a realtime report were verified against property `566046374`. The OAuth scope is `analytics.readonly`; write tools are disabled. The private OAuth app is in Testing with one test user. Google expires these refresh tokens after seven days, so periodic re-authorisation is required.

See `docs/seo-audit.md` for keyword assumptions, verification limits and the migration checklist. `docs/metadata-audit.json` is generated by the audit script.

A minimal XML fallback is available at `sitemap-pages.xml`. Both maps cover the same 18 canonical URLs. See `docs/sitemap-investigation.md` for the distinction between successful Google live retrieval and the still-pending sitemap processing report.

## Partner banner

`content/partner.json` controls the Trawel Pulse copy, destination languages and UTM campaign. The banner appears below the header on all content pages; privacy pages have no promotion. RU links to `/ru`, EN to `/en`. Greek copy links to `/en` because the destination currently supports only Russian and English.

The link opens the public citizenship calculator at `#citizenship-preview` with `utm_source=cyprus_schengen_monitor`, `utm_medium=referral`, `utm_campaign=cyprus_citizenship` and `utm_content=<source-language>_<page>` (for example, `el-CY_forecast`). Partner links use `rel="sponsored"`. Consent-based GA4 tracks `partner_click` with the source page, source language and full campaign URL, without also firing `source_click` for the same click.
