# Cyprus Schengen Monitor

A static, source-linked monitor of Cyprus's accession to the Schengen area.

Production URL: https://chistopat.github.io/cyprus-schengen-monitor/

The Russian edition is at the project root. English is under `en/`; Greek for Cyprus (`el-CY`) is under `el/`. Every edition includes the overview, timeline, forecast, participants, sources and privacy pages. The information snapshot is dated 27 November 2026. Political targets and analytical scenarios are distinguished from adopted legal decisions.

## Build and check

Python 3.12 and Node.js are sufficient for the website build and checks. No package installation is needed.

```sh
python build.py
python scripts/audit_site.py
node --check dist/assets/site.js
node --check dist/assets/analytics.js
python -m http.server 8765 --directory dist
```

`build.py` generates the Russian pages, then `scripts/localize.py` builds all language versions, metadata and the multilingual sitemap. `content/monitor.json` holds events and source URLs. `translations/*.json` contains aligned text translations; the build stops if a translation is missing. `content/seo.json` holds unique page titles and descriptions. `site.json` contains the production URL, public GA4 Measurement ID and optional search-engine verification tokens. Never put credentials or Analytics API secrets there.

The map variants are committed assets. To regenerate them, install Pillow, NumPy and SciPy locally, then run `python content/illustrate.py --language en` (or `ru`/`el`). Font lookup supports the original Linux fonts and macOS system fonts.

## Publication

The GitHub Actions Pages workflow builds the website, audits its metadata and links, checks JavaScript syntax and deploys `dist/` on pushes to `main`. GitHub Pages must use GitHub Actions as its publishing source. No advertising campaign or Google Ads billing is required to host the website or collect GA4 statistics.

## Analytics and search

GA4 uses Measurement ID `G-TPP3V2T4J9`. Analytics loads only after consent; preview hosts do not send events. Tracked interactions include page views, source-link clicks, timeline filters and opening timeline entries. On-site search text is not sent. Visitors can change consent in the footer. Advertising personalisation and Google Signals are disabled in the tag configuration.

The official Google Analytics MCP is configured separately in the user's Codex settings. Its OAuth credentials must remain outside this repository. Adding an MCP entry alone does not establish authenticated access.

See `docs/seo-audit.md` for keyword assumptions, verification limits and the migration checklist. `docs/metadata-audit.json` is generated by the audit script.
